Q: What is Nexelin?
A: Nexelin is an AI-powered customer support platform that enables businesses to create intelligent chatbots and virtual assistants. The platform uses Retrieval-Augmented Generation (RAG) technology to provide accurate, context-aware responses based on your company's knowledge base. Nexelin integrates with multiple messaging channels including WhatsApp, Telegram, Web Chat, and Email, allowing you to provide 24/7 AI-powered customer support across all your communication channels.

Q: How do I add documents?
A: You can build your AI's knowledge base by uploading documents in the Training section. Supported formats include PDF, DOCX, TXT, CSV, XML, and JSON files. Simply go to Training → Upload Files, select your documents, and they will be automatically processed. The system extracts text, creates embeddings, and stores them in a vector database for semantic search. You can also add text blocks directly, import web content, or use the Chrome extension to scrape website content. All documents are automatically chunked, embedded, and indexed for fast retrieval when customers ask questions.

Q: How to set up WhatsApp?
A: Nexelin supports WhatsApp Business integration via Meta's WhatsApp Business API. To set it up: 1) Go to Integrations → WhatsApp, 2) Enable WhatsApp integration, 3) Enter your Meta WhatsApp Business Account ID (WABA ID), App ID, App Secret, Phone Number ID, Access Token, and Verify Token from your Meta Business account, 4) Save the configuration. Once configured, customers can message your WhatsApp Business number and receive AI-powered responses. The system handles incoming messages, generates AI responses based on your knowledge base, and sends replies automatically. You can also generate QR codes for easy customer onboarding.

Q: How to set up Telegram bot?
A: Nexelin supports Telegram Bot integration. To set it up: 1) Go to Integrations → Telegram, 2) Enable Telegram Bot, 3) Get a bot token from @BotFather on Telegram, 4) Enter the bot token in the settings, 5) Save the configuration. The webhook URL is automatically configured. Once set up, customers can interact with your Telegram bot, and it will respond using your AI knowledge base. The bot supports text messages, commands, and can handle multiple conversations simultaneously.

Q: How to set up web chat?
A: Web Chat is a B2C chat interface that allows customers to chat directly with your AI assistant. It's available for all clients. To configure it: 1) Go to Integrations → Web Chat, 2) Generate a QR code or copy the chat link, 3) Share the link or QR code with your customers. The chat interface is accessible via URL like 'https://your-domain.com/client?tag=YOUR_TAG'. Customers can open this link and start chatting with your AI assistant. The chat supports text messages, voice input, and photo uploads. All conversations are saved in the History section.

Q: What is web widget?
A: Web Widget is a floating chat button that you can embed on your website. It's available for white label clients only. To set it up: 1) Go to Integrations → Web Widget, 2) Enable Web Widget, 3) Copy the generated HTML code, 4) Paste it into your website's HTML before the closing </body> tag. The widget will display a chat button on your website. When customers click it, a chat window opens with your AI assistant. The widget automatically adapts to mobile devices with a full-screen interface and close button.

Q: How to set up email?
A: Nexelin supports SMTP email integration for sending and receiving emails via AI. To configure it: 1) Go to Integrations → Email SMTP, 2) Enable Email SMTP, 3) Enter your SMTP server details (host, port, username, password), 4) Configure TLS/SSL settings, 5) Set the 'From' email address and name, 6) Save the configuration. Once configured, the system can send automated email responses and process incoming emails using your AI knowledge base. The integration supports standard SMTP servers including Gmail, Outlook, and custom email servers.

Q: What is sandbox?
A: The Sandbox is a testing environment where you can interact with your AI assistant before deploying it to customers. Go to Sandbox in the navigation menu to access it. You can ask questions, test different prompts, upload photos for analysis, and see how your AI responds. This helps you refine your knowledge base and system prompts before going live. The Sandbox uses the same AI model and knowledge base as your production chat, so you get accurate previews of customer interactions.

Q: How to test AI responses?
A: Use the Sandbox feature to test your AI responses. Go to Sandbox in the navigation menu. You can ask questions, test different prompts, upload photos for analysis, and see how your AI responds. This helps you refine your knowledge base and system prompts before going live.

Q: Where can I see conversations?
A: All customer conversations are saved in the History section. Go to History in the navigation menu to view them. You can see conversations from all channels (WhatsApp, Telegram, Web Chat, Email). The history shows: customer messages, AI responses, timestamps, conversation duration, and source channel. You can filter conversations by date, search for specific topics, and view detailed conversation logs.

Q: What is the dashboard?
A: The Dashboard provides an overview of your AI assistant's performance and activity. It displays key metrics including: total conversations, total messages, conversion rate, active conversations, and messages by type (Web, Telegram, WhatsApp). You can also see recent activity feed, top prompts that customers ask, and model status information. The dashboard helps you monitor usage, track performance, and identify trends in customer interactions.

Q: Which AI models are available?
A: Nexelin supports multiple LLM (Large Language Model) providers. You can configure your preferred AI model in the Training → LLM Provider section. Available providers include OpenAI (GPT-3.5, GPT-4, GPT-4 Turbo), Anthropic (Claude models), and other compatible providers. Each provider offers different models with varying capabilities, response times, and costs. You can select the model that best fits your needs based on accuracy requirements, response speed, and budget.

Q: How to customize AI responses?
A: You can customize your AI assistant's behavior using system prompts. Go to Training → Prompt Book to access prompt management. System prompts define how your AI should respond, its tone, personality, and specific instructions. You can create multiple prompts for different scenarios, edit existing ones, and test them in the Sandbox. Prompts help ensure your AI provides consistent, brand-aligned responses that match your company's voice and customer service standards.

Q: What is white label?
A: White Label is a feature available for enterprise clients that allows full branding customization. White label clients can: use their own domain name for the chat interface, customize the portal with their company logo and name, access Web Widget integration, and have a fully branded customer experience. The chat interface and client portal will display your company's branding instead of Nexelin branding.

Q: What is the Chrome extension?
A: Nexelin offers a Chrome browser extension that allows you to easily add website content to your knowledge base. Install the extension from the Chrome Web Store, then: 1) Visit any website you want to add, 2) Click the Nexelin extension icon, 3) Enter your client token, 4) Click 'Send Page Data' to scrape and add the content. The extension extracts text, images, and structured data from web pages and automatically adds them to your knowledge base.

Q: How do I get started?
A: To get started with Nexelin: 1) Log in to your client portal, 2) Go to Training and upload your first documents (PDFs, Word docs, or text files) to build your knowledge base, 3) Configure your AI model and system prompts in Training → LLM Provider and Prompt Book, 4) Test your AI in the Sandbox to ensure it responds correctly, 5) Set up integrations (WhatsApp, Telegram, Web Chat, or Email) in the Integrations section, 6) Generate QR codes or chat links to share with customers, 7) Monitor conversations in History and refine your knowledge base based on customer questions. The Setup Instructions page provides detailed guides for each integration.

Q: How do I log in?
A: Nexelin supports multiple authentication methods. You can log in with email and password on the Login page, or use automatic login via client tag. Client tag is a unique identifier for your account. When you access the portal via URL like '/l?tag=YOUR_TAG', you're automatically logged in without entering credentials. This is convenient for bookmarking and sharing access links.

Q: How long does file processing take?
A: After uploading a document, the system automatically processes it in the background. Processing includes: text extraction, chunking into smaller pieces, generating embeddings (vector representations), and indexing for search. Processing time depends on file size and complexity, typically taking a few seconds to a few minutes. You can see the processing status in the Training → Documents list. Files show as 'Processing' until complete, then automatically update to 'Processed'. The system checks status every 5 seconds. Once processed, the content is immediately available for AI responses.

Q: How to generate QR codes?
A: QR codes provide an easy way for customers to start chatting with your AI. You can generate QR codes in the Integrations section. For WhatsApp: go to Integrations → WhatsApp → Generate QR Code. For Web Chat: go to Integrations → Web Chat → Generate QR Code. Each QR code can be customized with a name, description, and location. When customers scan the QR code with their phone, they're automatically directed to start a chat. QR codes are useful for physical locations, printed materials, or sharing via social media.

Q: Can I use API?
A: Yes, Nexelin provides a comprehensive REST API for programmatic access. API keys can be generated in your account settings. The API allows you to: upload documents, query the AI, retrieve conversation history, manage integrations, and access all platform features programmatically. API documentation is available in the admin panel, and endpoints support standard HTTP methods (GET, POST, PATCH, DELETE). All API requests require authentication via API key in the X-API-Key header.
